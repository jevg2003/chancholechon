# Fuentes de las skills SEO y web

Se han incorporado archivos de skills de terceros a este repositorio para asistir en futuras revisiones del sitio.

- **modern-web-guidance**: https://github.com/GoogleChrome/modern-web-guidance — Apache-2.0. La skill usa el CLI `npx -y modern-web-guidance@latest` para recuperar guías actualizadas sobre rendimiento, accesibilidad y API web. Copiar el SKILL.md no ejecuta el CLI ni lo instala como dependencia del sitio.
- **seo-audit**: https://github.com/coreyhaines31/marketingskills — licencia MIT. Se incluye la skill y las referencias citadas en ella para auditorías técnicas y SEO local.

Las licencias completas acompañan a cada skill. Estas skills son herramientas de asistencia para agentes, no código servido a visitantes ni plugins de Astro.
